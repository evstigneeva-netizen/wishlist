# Wishlist — список желаний

## Что это
Веб-приложение "список желаний": пользователи создают и ведут свои вишлисты, добавляют желания, делятся с другими.

## Стек
- Framework: Next.js 15 (App Router, TypeScript)
- Стили: Tailwind CSS
- ORM: Prisma
- База данных: SQLite (dev) → PostgreSQL (prod)
- Деплой: Vercel

## Структура проекта
```
src/
  app/          — страницы и API routes (App Router)
  components/   — React-компоненты
  lib/          — утилиты, prisma client
prisma/
  schema.prisma — схема БД
```

## Ключевые правила
- Коммитить только после явной просьбы
- Перед крупными изменениями — уточни у пользователя
- Код без лишних комментариев
- Не добавлять фичи сверх задачи
- Компоненты — в src/components/, серверная логика — в src/lib/

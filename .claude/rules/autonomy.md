# Правило: автономность

Делай сам, не переспрашивай:
- Читать файлы и структуру проекта
- Создавать/редактировать код в рамках задачи
- Запускать тесты и линтеры
- Создавать новые файлы и папки внутри проекта

Обязательно уточняй у пользователя:
- Выбор архитектурного решения, если не очевидно
- Удаление файлов или данных
- Изменение конфигурации деплоя
- Любые действия с production
- Git push и создание PR

# Правило: коммиты

- Коммитить только когда пользователь явно просит
- Не использовать `git add .` или `git add -A` — только конкретные файлы
- Не пушить без явного разрешения
- Не использовать --no-verify
- Сообщение коммита: краткое, на русском или английском, описывает "почему", а не "что"
- Не коммитить .env, секреты, бинарники

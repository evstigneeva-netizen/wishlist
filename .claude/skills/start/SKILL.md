# Skill: start

Инициализация рабочей сессии.

## Шаги
1. Прочитать CLAUDE.md — понять контекст проекта
2. Прочитать .claude/SNAPSHOT.md — восстановить состояние
3. Запустить `git status` — проверить незакоммиченные изменения
4. Запустить `git log --oneline -5` — последние коммиты
5. Доложить: текущий статус проекта, что было в процессе, что делать дальше

## Вызов
/start или "начни сессию"
